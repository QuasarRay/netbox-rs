# netbox-rs

Rust tooling and generated protobuf contracts for the NetBox API.

The protobuf contracts under `proto/netbox/` are generated by the Rust binary at `src/bin/netbox_openapi_proto.rs` from the committed NetBox OpenAPI snapshot at `openapi/openapi.json`.

## Regenerate

```sh
cargo run --bin netbox_openapi_proto -- \
  --input openapi/openapi.json \
  --output-dir proto/netbox \
  --package netbox.v1
```

## Verify without modifying files

```sh
cargo run --bin netbox_openapi_proto -- \
  --input openapi/openapi.json \
  --output-dir proto/netbox \
  --package netbox.v1 \
  --check
```

OpenAPI is treated as the public API contract. NetBox models and migrations remain authoritative for persistence semantics.
